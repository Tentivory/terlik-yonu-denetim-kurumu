# Terlik Yönü Denetim Kurumu

> Resmî slogan: “Burun kapıya, topuk vicdana.”

Bu depo, ev içi terliklerin burun yönünü denetleyen bağımsız, gereksiz ve son derece ciddi bir kamu kurumu simülasyonudur. Kurum 01 Ekim 2026 sabahı, biri sola bakan biri sağa bakan bir çift terliğin antrede diplomatik kriz çıkarması üzerine kurulmuştur. Kriz 4 dakika sürmüş, çay soğumuş, kurum kalmıştır.

## Misyon

Terliğin burun ucu kapıya bakmıyorsa bu bir moda değil, bir yönetmelik ihlalidir. İhlalin cezası yoktur. Cezası olmaması da ayrı bir ihlaldir. Kurum her iki ihlali de tutanağa geçirir, sonra çay ister.

## Vizyon

2040 yılında tüm antrelerin terlikleri aynı yöne bakacak. Kimse bunu istemiyor. Kurum yine de istiyor. İstemek yeter.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Terlik zorunlu değildir ama denetim daha inandırıcı olur.

```bash
python terlik_denetim.py
python terlik_denetim.py --cift sol sag --oda antre --tutanak
python terlik_denetim.py --rastgele 5
```

## Örnek çıktı

```
TUTANAK NO: TYDK-2026-0042
Oda: antre
Sol terlik: kapıya bakıyor (uygun)
Sağ terlik: buzdolabına bakıyor (kuşkulu)
Karar: Sağ terlik ihtar aldı. İhtar sözlü değil, içten.
```

## Kuruluş şeması

| Birim | Görev | Yetki |
| --- | --- | --- |
| Burun Komisyonu | Yön ölçer | Ölçer, karar vermez |

| Antre Sekreterliği | Tutanak yazar | Yazıyı kaybeder, tekrar yazar |
| İç Çekiş Dairesi | Ceza infaz | Sadece iç çeker |
